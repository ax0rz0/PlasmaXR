# Meta system packages, grouped by how risky they are to turn off.
# Format:  group | package | what it is
#
# optional   Apps and services nothing else depends on. Removing them frees RAM and removes UI
#            clutter; the headset keeps working exactly as before.
# maybe      Probably unused, but they may back a feature you use (Link, the phone app). Only ever
#            disabled by naming them explicitly.
# social     Presence, friends and avatar features.
# hud        The system overlays (control bar, display bar, universal menu, notifications). Only
#            disable these once Plasma XR can do their jobs itself - see docs/META_SHELL.md.
#
# Never listed here, on purpose: vrruntimeservice (the OpenXR runtime), vrguardianservice (boundary),
# horizon (platform service), os.cm, configuration, oemconfig, systemdriver, deviceauthserver,
# maintenanceboot, anything under vendor.oculus.* and the android core.
